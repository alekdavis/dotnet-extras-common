      ObjectExtensionsIsPartialEquivalentTo Method

      Note: This API is now obsolete.
      Checks if the source value is null or an equivalent of a target value; or if every element of a source array, list or dictionary is a subset of the corresponding target array, list or dictionary, or if every property and field of a source object is a subset of the corresponding property or field of the target object.

      Usage Note

      In Visual Basic and C#, you can call this method as an instance method on any object of type Object. When you use instance method syntax to call this method, omit the first parameter. For more information, see Extension Methods (Visual Basic) or Extension Methods (C# Programming Guide).

      Remarks

      The source and target objects are considered partially equivalent if their data types are compatible (e.g. int and long are compatible) and they meet the following criteria:

      • For all data types, the nullvalue of the source object is considered a partial match of the target.

      • For simple types, such as string, int, DateTime, etc., both the source and target values can be typecast to the same type and found equal.

      • For arrays, list, and collection types, the source must contain the same or a lesser number of elements than the target, and each element of the source must be equivalent to the corresponding item of the target.

      • For dictionaries, the source must contain the same or a lesser number of elements, and each element of the source must be equivalent to the corresponding item of the target found under the same key.

      • For hash sets, the source must contain the same number or a lesser number of elements, and the values in both hash sets must match.

      • Comparison of string values is case-sensitive.

      Example

      User source = new() { Id = 1, Email = "joe@mail.com", Name = new() { GivenName = "Joe" } }; User target1 = new() { Id = 1, Email = "joe@mail.com" }; User target2 = new() { Id = 2, Email = "joe@mail.com", Name = new() { GivenName = "Joe", }, }; Assert.True(source.IsPartialEquivalentOf(target1)); Assert.False(target1.IsPartialEquivalentOf(source)); Assert.False(source.IsPartialEquivalentOf(target2));
