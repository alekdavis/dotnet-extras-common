      Remarks

      The deserialization routine will try to convert JSON objects to the following primitive types:

      • Boolean (true/false)

      • Numeric (integer, long, decimal, double; depending on the value and precision)

      • Date and time offset (converted from the string value)

      • Date and time (converted from the string value)

      • String

      • List (of objects)

      • Dictionary (string key, object value)

      Keep in mind that this converter is only applied when the target property type is Object. The code logic will attempt to guess what the most appropriate type for the value would be by attempting to perform conversions to the above mentioned primitive types.

      The code was adapted from https://stackoverflow.com/a/65974452/52545 and https://learn.microsoft.com/en-us/dotnet/standard/serialization/system-text-json/converters-how-to#deserialize-inferred-types-to-object-properties.
